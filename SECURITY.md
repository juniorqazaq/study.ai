# Security Policy

## Supported Versions

This project is under active development. Security fixes are primarily applied to the latest version of the repository.

| Version | Supported |
| --- | --- |
| Latest | Yes |
| Older commits / snapshots | No |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public GitHub issue.

Instead, report it privately by contacting the project maintainer with:

- a clear description of the issue
- steps to reproduce it
- the possible impact
- any suggested fix or mitigation, if available

## What to Include

To help with triage, please include as much of the following as possible:

- affected area or feature
- reproduction steps
- proof of concept, if safe to share
- severity estimate
- environment details

## Response Process

After a report is received, the maintainer will aim to:

- confirm receipt of the report
- investigate and validate the issue
- work on a fix or mitigation
- coordinate disclosure when appropriate

## Disclosure Policy

Please allow time for the issue to be investigated and fixed before sharing details publicly.

Responsible disclosure helps protect users, contributors, and the project.
