# Contributing to AI-Studybook

First off, thank you for considering contributing to AI-Studybook! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How to Contribute

### 1. Fork the Repository
Click the "Fork" button at the top right of the GitHub repository page to create your own copy of the project.

### 2. Clone Your Fork
```bash
git clone https://github.com/YOUR_USERNAME/ai-studybook.git
cd ai-studybook
```

### 3. Create a Branch
Use descriptive branch names to identify the work you are doing.
- `feature/new-study-module`
- `bugfix/fix-login-error`
- `docs/update-readme`

```bash
git checkout -b feature/my-amazing-feature
```

### 4. Commit Message Guidelines
We follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:
- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation changes
- `style:` for formatting changes
- `refactor:` for code restructuring

Example: `feat: add AI-powered note summarization`

### 5. Code Style
- Follow the existing project structure.
- Run linting before committing: `npm run lint`.
- We use TypeScript and React with Tailwind CSS.

### 6. Pull Request Process
1. Push your changes to your fork.
2. Navigate to the original repository and click "Compare & pull request".
3. Provide a clear description of your changes and link any related issues.
4. Ensure all CI/CD checks pass.
5. Once your PR is reviewed and approved, it will be merged!

## Community
- Join our discussions in the GitHub Issues or Discussions tab.
- Be respectful and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for your contributions!
